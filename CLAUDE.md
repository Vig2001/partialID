# Confidence Intervals for Data-Fusion-Based Partial Identification

Point identification (ID) of causal estimands rely on certain strong, untestable assumptions, such as no unobserved confounding in a non-randomised or observational study (OS), or (conditional mean) study exchangeability of potential outcomes (POs). When such an assumption is relaxed point ID is no longer possible and so the alternative is partial ID, which yields a band that contains the true causal quantity rather than a single point estimate. Until recently, such bands have been derived primarily by relaxing a single assumption in a single dataset (OS or RCT). Work done by \cite{lanners_data_2025} aim to minimise the width of the identification band, by intersecting bands from both an OS and an RCT. This project aims to extend this line of work, by focusing on minimising the width of the corresponding confidence interval for (a) the fused ID band and (b) the causal estimand of interest. We first motivate our method using simulation studies, before applying it to sensitivity regimes. \\

## Corrections

<!-- Claude adds entries here, e.g. "Use \citet not \cite for in-text citations" -->
- Don't call a valid CI "wider" or "rarely narrower" than one that undercovers; width comparisons only make sense between methods with valid coverage.
- Each new talk gets its own folder inside `Slides/`; never put a talk's `.tex` directly in `Slides/`.
- Respect each section's stated assumptions: in the known-variance Gaussian section, never suggest replacing $\sigma_k^2$ with an estimate.
- Write derivations in the paper as connected prose between displays, never with bold "Step 1, Step 2, …" or "Result." headings.
- When variances are estimated, don't contrast with the known-variance Gaussian section; say validity relies on the variance estimators being consistent for the truth.
- Table captions go above the table, figure captions below (since 2026-11-11; `compiled.tex` loads `caption` with `\captionsetup[table]{position=top}` for the spacing). Keep captions lean: conventions shared across a simulation's tables and figures (nominal level, replications, what coverage and bold mean, folds, no inequality selection, the row rule) live in that simulation's setup text, not in each caption; MC s.e. as one "at most" clause from the `...Max` macros.
- Don't rank methods by how often each is narrowest per cell: that uses hindsight no practitioner has. Compare rules fixed in advance by their median and worst-case width relative to the per-cell best.
- Cross-fitting an estimator with nuisances means standard cross-fitting: fit the nuisances on the other folds and predict on the held-out fold. Don't port the toy's fold-alone fits (no nuisances there) to such estimators.
- Related work: the closest papers are Lanners et al. (2025), Chernozhukov, Lee & Rosen (2013) and Yu et al. (2026; JRSS-B vol. 88, the published version of arXiv 2412.03731). Han & McCloskey (2024) concerns a parameter selected from data, a different target, so it is not close work. Keep econometric references to a minimum; the contrast is that they don't combine data sources for partial ID, which is what lets us use data fusion methods.
- Since 2026-11-11 (supervisor): no single-dataset comparators (dataset 1/2, large/small OS) in any paper table or figure, and the causal box plots show CI width / true band width on a log scale (binary: Lambda_1 in [2, 4], Lambda_2 in (1, 2], stated in the panel title, not the caption). Plan `done/2026-11-11_drop-single-dataset-truth-ratio.md`.
- Since 2026-11-11 the files the paper inputs are named `fig_|tab_<content>_<mt|app>` (main text or appendix; e.g. `fig_undercoverage_mt.pdf`, `tab_toy_band_ends_app.tex` + `_macros.tex`), with no hash; the hash and command go in PROVENANCE.md, with the old name.
