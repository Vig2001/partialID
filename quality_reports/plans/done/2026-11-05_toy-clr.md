## Method

Chernozhukov, Lee and Rosen (2013, Econometrica 81(2); arXiv 0907.3503),
Algorithm 1, for two independent estimates, per end. Upper end
min(U_1, U_2):

1. Selection: keep dataset j if U_j <= min_i(U_i + k_gamma se_i)
   + 2 k_gamma se_j, k_gamma = Phi^{-1}(sqrt(gamma_n)),
   gamma_n = 1 - 0.1 / log n, n = n_1 + n_2 = 2500 (gamma_n = 0.987,
   k_gamma = 2.49).
2. k_p = Phi^{-1}(p^{1/m}), m = number kept; p = 1 - alpha / 2 per end
   (Bonferroni over the two ends, as for every other method): 2.239 or 1.960.
3. CI end: min over both datasets of U_j + k_p se_j.
4. Lower end: mirror image.

Closed form because the datasets are independent; no random draws.
L_hat, U_hat: CLR's half-median-unbiased estimator (p = 1/2). w_L, w_U: 1
where dataset 1 attains the CI end.
